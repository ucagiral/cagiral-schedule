    Let this device save changes

    Reading the schedule needs nothing. To edit from this device, GitHub needs a token — a long password that only lets this one app change this one file. You make it once, here:

    1. Open github.com → your picture (top right) → Settings
    2. Scroll to the bottom of the left menu → Developer settings
    3. Personal access tokens → Fine-grained tokens → Generate new token
    4. Name it anything. Under Repository access pick Only select repositories → cagiral-schedule
    5. Under Permissions → Repository permissions, set Contents to Read and write
    6. Generate token, copy it, and paste it below

    It's stored only on this device and never leaves it except to talk to GitHub.

    Reminders in your Calendar app

    Subscribe once and your Calendar app keeps itself up to date — alerts 15 minutes before anything hands-on. You never import anything again.

    iPhone: Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar → paste.

    Mac: Calendar app → File → New Calendar Subscription → paste.

    Apple refreshes subscriptions on its own schedule (usually about an hour), so a change you make now may take a little while to reach the Calendar app. The app you're looking at is always instant.
