# Looping query results

Generated by [`../tools/loops/`](../tools/loops/) — see
[`../protocols/chromatin-loops.md`](../protocols/chromatin-loops.md) for the data sources and
the rules for reading a report without over-claiming.

Each query drops a pair of files here, both rendered from the same rows:

- `<slug>.md` — the report. Verdict, the four evidence layers, caveats, every source linked.
- `<slug>.xlsx` — the numbers. Five flat sheets (`loops`, `contact_matrix`, `tads`, `ctcf`,
  `datasets`), one row per observation, no charts — built to pivot and plot from.

To add one: GitHub → **Actions → Chromatin looping query → Run workflow**.

`_datasets.json` is the portal crawl cache. It is gitignored and lives in the Actions cache
instead: it is a crawl result rather than a source file, and it is large.
